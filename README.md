# helpMEI

Protótipo navegável do MVP do **helpMEI**, marketplace de serviços entre MEIs da economia criativa: divulgação, pedido rápido, match com quem pode atender, chat, combinado, pagamento protegido com confirmação de recebimento e avaliação.

Projeto do Grupo 2 no Hackathon Negócios em Transformação (UniSenac, Senac RS e Sebrae).

## Como rodar

É uma página estática, sem dependências. Abra o `index.html` no navegador ou publique em qualquer hospedagem estática (Vercel, Netlify, GitHub Pages).

### Deploy na Vercel
1. Importe este repositório em vercel.com/new.
2. Framework Preset: **Other**. Não precisa de build command nem de output directory.
3. Clique em **Deploy**.

> Pessoas, valores, avaliações e perfis de redes sociais do protótipo são fictícios.
